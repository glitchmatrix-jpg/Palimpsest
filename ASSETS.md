# Asset Notes

The tarot artwork in `assets/cards/` is maintained separately from the application code.

Before public release, verify and document the provenance and reuse terms for the final
card artwork and any source material used to create it.

Do not assume that the MIT license covering Palimpsest source code automatically applies
to third-party or derived artwork.

The `QA/` files from the source deck package are retained under `docs/asset-qa/` for
verification and provenance tracking.
