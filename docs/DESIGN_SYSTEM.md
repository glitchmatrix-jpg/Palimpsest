# Palimpsest — Design System

## Visual direction
Dark violet, ivory, muted gold, and generous negative space.

The interface should feel:
- literary
- modern
- calm
- symbolic
- visually rich without visual clutter

## Hard rule
No screen should look like a database viewer.

## Graphics
Use the finalized tarot card artwork as the primary card visuals.
Use SVG/CSS for:
- Fool's Journey paths
- suit diagrams
- progression diagrams
- spread relationships
- teaching illustrations
- pattern indicators

## Interface pillars
- Learn
- Cards
- Read
- Journal

## Motion
Subtle only:
- card flips
- fades
- short path/line animations
- selected-card scaling
- section transitions

Avoid:
- constant sparkles
- heavy parallax
- 3D deck physics
- decorative animation with no teaching/interaction value
