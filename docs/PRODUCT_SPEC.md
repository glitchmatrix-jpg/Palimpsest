# Palimpsest — Product Specification

## Product identity
A lightweight, visually rich tarot learning, reading, and journaling web app.

## Core pillars
1. Learn
2. Read
3. Journal

## Learn
- Start here
- Major vs Minor Arcana
- The Fool's Journey
- Four suits
- Ace through Ten
- Court cards
- Upright vs reversed
- Practice and quizzes
- Three-card connection exercises

## Read
- Physical-deck card selection
- Optional digital draw
- One-card readings
- Past / Present / Future
- Situation / Challenge / Advice
- Position-aware individual meanings
- Holistic multi-card synthesis
- Relationship explanations and pattern detection

## Journal
- Saved readings
- Personal notes
- Search/filter
- Local-only persistence
- Export/import backup

## Explicit V1 exclusions
- Accounts
- Cloud sync
- Social network
- Astrology
- Notifications
- Bundled AI model
- Server backend
